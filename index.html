The concerns

But investors ask five questions

1 · Custody

Who holds my keys?

FTX, 2022: $0bn missing

2 · Ownership

Is the token legally mine?

3 · Code

What if the code has a bug?

Hacks, 2024: $0bn stolen

4 · Privacy

Can everyone see my money?

5 · Exit

Can I sell it or get cash back?

What our code taught us

Our own code shows two of these worries

No undo button

uint public immutable fixedRate;

Once live, nothing can change. A bug or a lost key stays forever.

No one to call

require(msg.sender == borrower);

Only the borrower can pay back. If they don't, the code can't force them.

Our advice

Before investing, ask three questions

Question 1

Is it mine?

A clear law says the token is my asset.

Question 2

Is it safe?

A regulated firm holds the keys.

Question 3

Can I get out?
