# Blockchain in asset servicing: what worries investors?

Final presentation for 3.DTF2 Blockchain and Cryptocurrency Markets (Blockchain institutional adoption, Aymeric Lovat), University of Luxembourg, November 2026.

Group 6: Shohjahon Hakimov, Sofia Neves Gonçalves, Charis Thanasis.

`index.html` is a single-file animated slide deck (10 slides, about 8 minutes). Open it in any browser, or view it on GitHub Pages.

- `→` / `Space`: next click · `←`: back
- `P`: presenter view (speaker, script per click, timer, hand-offs, Q&A prep)
- `F`: full screen · `T`: start/pause timer
- **Cheat sheet** button: the full script on one page (print with Ctrl/Cmd + P)

Open the page in two windows (presenter view on the laptop, full screen on the projector) and they stay in sync.
